Boundary 1: Client Edge Sandbox
Zone: Field worker mobile device & browser.
Trust Level: Untrusted.
Threats: Device clock manipulation, mock GPS location providers, hardware spoofing, network loss.
Mitigations: Haversine spherical validation, hardware fingerprinting, live selfie stream only (gallery upload strictly disabled), offline Hive queue with immutable original timestamp.
Boundary 2: Public Internet Transport
Zone: Cellular data / Public Wi-Fi / Edge networks.
Trust Level: Untrusted Transit.
Threats: Man-in-the-Middle (MitM), replay attacks, packet interception.
Mitigations: TLS 1.3 encryption, Supabase Bearer JWT auth headers, UUIDv4 idempotent replay prevention.
Boundary 3: Cloud Platform (Supabase)
Zone: Managed PostgreSQL 15, Auth, Storage, & pg_cron.
Trust Level: High Trust (Authoritative Data Tier).
Threats: Cross-tenant data leakage, unauthorized privilege escalation.
Mitigations: Row-Level Security (RLS) on all 15 tables enforcing organization_id isolation, service role restrictions, stored procedures for atomic role transfers.
Boundary 4: External SaaS APIs
Zone: Firebase Auth, Google Gemini API, Resend, WhatsApp.
Trust Level: Third-party Delegated Trust.
Threats: API quota limits, third-party outages, credential compromise.
Mitigations: Local DB fallback on auth failure, rate limiting, secure storage of API keys in compliance_notification_settings table.
